## v0.82 · 2026-11-14（777 外模索引绘制）

基线为 v0.81，已有 11 机型、FlightGear 777-300ER 外模和涂装、中文飞行简报、DX11/DX12、FXAA、浦东离线影像、可交互通用座舱及 PFD/NAV/ENGINE、训练导航与生涯。上版 Linux 46/46、模型导入及菜单布局通过。随后审查发现 CPU 已复用唯一顶点，但图形提交仍展开全部可见三角形。

Linux Release（Assimp ON）构建与 48/48 CTest 通过。严格 C++17 机型检查、原 DX11/DX12 非索引上传检查及六页菜单布局检查通过。Windows 编译结果以本版 GitHub 工作流为准。

本轮改用两个 DirectX 后端的索引绘制，按相同顺序绘制场景和外模。放轮外模逻辑上传数据减少 66.1%，收轮减少 54.3%。按真实资产检查了放轮、收轮、再次放轮和清除外模，重建的三角形数据与原路径逐字节一致。见 INDEXED_777.md 与 validation_v082。

仍缺 777 专用交互座舱、完整机载系统与 FMS、真实气动标定、精细地景和天气，以及完整航班实机证据。微软官方对照 https://www.flightsimulator.com/microsoft-flight-simulator-2024/ 。下一步在 Boot Camp 以相同视角比较 v0.81/v0.82 的帧时间、内存和画面，再验收完整航班。
## v0.81 · FlightGear 777 与飞行简报菜单

基线为 v0.80。新增第十一机型 777-300ER。使用 FlightGear 的外部模型和涂装，转换为原生运行资源。DX11 和 DX12 使用独立贴图层及 mipmap。缓存原模型的重复顶点，将每次绘制的顶点变换从 91,548 次降为 23,447 次。起落架按状态显隐。

开始和暂停使用同一套飞行简报布局。左侧是主要操作，右侧显示当前机型、乘客、任务、积分和限帧状态。公开机库链接更新为已发布的免登录站点。

Linux Release 构建与 46 项 CTest 均通过。单独编译验证了 Assimp 转换器、旧机型导入回归与六个菜单页面。检查了777尺度、机头方向、起落架标签、索引映射、旋转后缓存和贴图 mip 链。结果见 validation_v081。

777 暂用通用驾驶舱与原型飞行参数。Windows 编译、游戏画面和 Boot Camp 帧率未验证。详见 FLIGHTGEAR_777.md。
