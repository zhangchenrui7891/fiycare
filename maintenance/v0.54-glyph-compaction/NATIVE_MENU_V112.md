## v0.112 · 2026-11-26 · 减少 Windows 原生菜单的逐帧写入

基线 v0.111 已支持浦东 A330 进近接地复盘。检查主循环发现，无论菜单是否打开、飞机是否变化，每帧都用 CheckMenuItem 写入 11 个机型、2 种地形、限帧和辅助回正共 15 个勾选状态。本版在原生菜单的生命周期内保存上次成功同步的机型、地形、限帧和辅助状态。首次显示与状态变化时同步，任何单项写入失败则在下次更新中重试。各机型沿用既有命令与配置映射。

以同样的 A330 状态执行 1,200 次更新，在计数替身上运行两个版本的实际菜单代码。v0.111 写入 18,000 次，v0.112 写入 15 次。此次对照只计菜单接口调用，不测量整机帧率。新回归覆盖 11 个机型、地形切换、限帧、辅助回正与失败重试。Linux Release 49/49 项 CTest 通过。测试输出、Windows 启动日志及原始截图放在 validation_v112。

项目已有中文交互座舱、11 个机型配置、DX11/DX12、FXAA、浦东本地影像、生涯与训练进近。机型专用航电、天气和机场运行细节与 MSFS 2024 的目标体验仍有差距。已有数值回归覆盖接地和滑跑，完整人工航班以及目标 MacBook Air 在正式资源下的性能、原生分辨率画面仍待验收。下一步优先进行相同进近、相同 DX11 渲染设置的 HD 6000 对照，记录帧时间和工作集。

Windows Server 2022 的 MSVC 测试创建项目的真实 Win32 菜单，用 GetMenuState 读取 A330 与 A350 切换前后的勾选结果，同时验证两种地形、辅助与限帧设置。兼容启动入口连续构建两次成功。DX11 WARP 使用简化资源渲染三帧并保存截图，MSVC 接地与滑跑回归、普通练习独立建档、上一版 PowerShell 复盘检查均通过。完整包包含本轮构建并校验的 Windows EXE。
