# v0.73 驾驶舱鼠标操作互斥

左键开始拖动油门后，再按右键不会转动视角，也不会夺走鼠标捕获；右键开始环视后，左键不会操作驾驶舱开关或菜单。需要结束当前操作并重新按下另一按钮，才能开始另一种拖动。松开未取得控制权的按钮不结束当前操作。

主程序使用 cockpit::Input 的 looking/dragging 状态，不再单独保存 lookDragging。失去鼠标捕获停止两种拖动但保留已排队的最终油门值；失焦、菜单或全屏切换使用既有 cancel 路径，清除拖动和未处理输入。本轮增加一个布尔状态，没有新贴图、每帧分配或地景负担，也没有实测性能提升结论。

## 自动检查

cockpit_input_tests.cpp 覆盖两种松键顺序、驾驶舱开关抑制、捕获丢失、取消和恢复。tools/check_pointer_integration.py 抽取 main.cpp 的实际鼠标消息处理语句（只规范换行），编译时以 CPU 函数代替 Win32 的捕获及窗口尺寸 API。ReleaseCapture 会同步调用捕获丢失消息，检查实际分支接线、菜单抑制及油门最终值保留。

相同脚本载入 v0.72 main.cpp 时，在“油门拖动期间按右键不能转动视角”断言失败；新代码通过。这证明模拟消息下的逻辑回归，不证明真实 Windows 消息投递或硬件表现。

2. 右键环视时点击/松开左键，确认开关、油门、菜单不变，环视继续；松右键后重新按左键可正常操作。
