# v0.103 座舱通知避让仪表

v0.102 的真实 Windows DX11 WARP 截图显示，位于逻辑 y=425–451 的通知条横跨默认座舱玻璃仪表。现在三维座舱（且非步行）将同一通知条放到 y=46–72，位于警告行 y=10–38 下方；追尾/俯视/步行沿用原 y=425。通知内容、5 秒时长、保存错误持续显示、失速/断电警告和菜单逻辑保留。

本轮没有增加分辨率、贴图、网格、绘制批次或仪表面板。原有一个背景矩形和文字仅改变座舱中的位置。顶部通知会暂时占用一部分挡风玻璃区域；本轮针对默认中立视角，不能据此保证所有环视角度下无覆盖。640×360 下仪表本身仍偏小，需要继续处理视角/可读性。

新增 check_notice_pixels.py，对真实 Windows WARP 的相同 640×360 人工纹理/程序训练机截图做回归比较。基线是已保存的 v0.102 原始截图 ZIP。座舱旧通知带（像素 y=282–302）与新通知带（y=29–49）必须分别有足够变化；两条带外和追尾图像允许最多 1% 像素差异，以防把场景改变误当布局修复。比较不评价帧率、完整画质或 HD6000 性能。未修改的旧截图作为对照输入时检查失败。

Windows 流程保留追尾/座舱各三帧、BMP 读回、必需资源缺失退出和存档哨兵检查，随后才执行布局比较。两张当前原始 BMP、基线、像素统计、日志及 EXE 来源将记录于 validation_v103。实际检查结果以本轮工作流和连续记录为准。

完整兼容包继续提供正式资源和静态运行库 Windows x64 EXE；Assimp 导入/旋转编辑关闭，完整源码可重建 Assimp ON。下一步改进低分辨率仪表视角/字号，并在 Boot Camp Windows 10 x64 点检正常飞行、保存失败、失速/断电、环视及菜单切换，采集 DX11 P95/工作集和完整航班证据。当前无目标机验收，与 MSFS2024 的成熟航电、气动、真实机场、天气和成品体验仍有明显差距。
