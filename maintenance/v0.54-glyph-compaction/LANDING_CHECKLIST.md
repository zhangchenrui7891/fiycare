# v0.92 F2 着陆检查

按 F2 打开工程面板。飞机处于离地状态、相对当前地形高度不超过 600 m、垂直速度低于 -0.5 m/s 时，面板自动显示六项着陆状态。v0.93 起，进入着陆检查后会保持到接地、坠毁、垂直速度达到 +1 m/s 或地形相对高度超过 700 m，随后恢复起飞检查。

| 检查项 | 通过条件 |
|---|---|
| 航电供电 | 当前航电已供电 |
| 起落架放下 | gear 为真 |
| 着陆襟翼 | 教练机大于 0，客机至少 50% |
| 停留刹车释放 | 停留刹车关闭 |
| 下降率不超过 6 m/s | 垂直速度至少 -6 m/s |
| 无失速警告 | 当前无失速警告且未坠毁 |

600 m 和襟翼阈值是当前游戏模型的提示规则。下降率阈值沿用已有低空下降率警告。检查只显示状态，不自动操纵或影响任务奖励。短暂平飞会保留着陆检查。阶段保持状态不写入存档，读档、重飞和换机时按新飞行状态重新判断。

Boot Camp 验收时先在停机位置打开 F2，确认起飞检查，再建立低空下降，点检起落架、襟翼和停留刹车。抬头复飞后检查标题恢复。观察六行状态是否在面板内、文字是否清晰，并用现有 DX11 基准记录同场景帧间隔和内存。实际 Windows 显示和 HD 6000 性能待实测。

状态保持由每帧更新的 AlertManager 管理，F2 隐藏时也继续更新。进入阈值仍是 600 m 和 -0.5 m/s，退出阈值分别采用 700 m 和 +1 m/s，避免临界位置来回切换。
