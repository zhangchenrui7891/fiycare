## v0.10 实机性能统计

修正原HUD以物理时间推算FPS的问题：暂停/恢复时不再因dt=0显示异常高帧率。新增真实墙钟帧间隔统计，最多保留300帧；显示平均FPS和P95帧时间，保留长卡顿。失焦、最小化和原生菜单恢复时清除统计窗口。数据包含渲染、Present等待和帧率限制，不是GPU耗时。

每约5秒写入 `%LOCALAPPDATA%\FlightCareerAir\performance.csv`（每次启动覆盖）。记录后端、机型、视角、地形、FXAA、低负载开关、模拟是否活动及统计值。切换场景后的300帧窗口可能包含前一场景；固定配置等待至少15秒再采集。CSV不可写时写启动日志，不阻止飞行。三帧烟雾检查不会产生有效性能样本。

### 操作

按C进入驾驶舱，或在设置中选择“三维驾驶舱 · 鼠标操作”，再开始飞行。

- 鼠标点击发动机、起落架、襟翼、辅助回正和停留刹车开关。
- 拖动右侧油门杆：向上增加、向下减少，范围0–100%；客机两个显示杆联动，当前不是独立双发控制。
- W/S和鼠标控制同一推力指令，F/G/I/L/V与对应按钮控制同一状态。
- 空速、高度、姿态、燃油和推力显示来自当前模拟状态；开关状态用实体颜色表示。
- 暂停、菜单、失焦、事故与步行状态禁止鼠标操作；离开驾驶舱或失焦取消拖动。
- 停留刹车持续制动，低速停稳后保持位置；起飞前点击释放或按V。
- v8存档保存停留刹车与FXAA，兼容v3–v7，旧存档默认FXAA开启；换机/重新出发释放停留刹车。

这是所有机型共用的简化三维驾驶舱：实体仪表台、窗框、开关、油门杆与三维仪表文字，随飞机姿态运动；并非A330/A350真实驾驶舱复刻。没有电气启动流程、独立发动机油门、FMS或自动驾驶。
引擎、起落架、襟翼均是现有简化物理系统的控制；按钮“开/关”不代表真实飞机的全部状态。
当前仍只交付源码，没有Windows EXE；鼠标操作、布局和截图须在Windows实测。

地表使用简化低起伏高程，未接入真实DEM。跑道和建筑是浦东附近的示意场景，没有复刻实际机场布局。
超出影像区域后回到程序地面颜色，不会无限重复卫星图。

## 在Visual Studio Community中运行

1. 安装Visual Studio Community及“使用C++的桌面开发”，包含MSVC、Windows SDK、C++ CMake工具。
2. 解压整个FlightCareerAir文件夹，双击build_vs.bat。
3. 脚本定位VS、构建x64 Release、执行数值/资源检查，再启动游戏。
4. 在中文主菜单进入“选择飞机与乘客”，选择A330或A350，再点“开始 / 继续飞行”。
5. 默认启用浦东卫星图；如需切换，在跑道停稳后打开“设置与视角”。
6. 在这台旧机器上先用run_compat.bat：DX11、640×360、20帧上限。

可用VS的“文件 → 打开 → 文件夹”打开工程。需要CMake 3.21以上；构建预设为Ninja，VS脚本初始化编译环境。

```bat
cmake --preset windows-release
cmake --build --preset windows-release
ctest --preset windows-release
out\build\release\FlightCareerAir.exe
```

CMake构建后自动把assets复制到EXE旁。移动EXE时必须同时移动整个assets文件夹；游戏从EXE目录定位资源，不依赖当前工作目录。
缺失或损坏的资源会产生错误提示与startup.log，不会默默改用替代飞机。
运行游戏无需Python。仅重新转换GLB时需要Python、numpy、Pillow：

```bat
python tools\convert_assets.py --source-dir assets\source --satellite assets\pvg_satellite.jpg --output assets
```

## 模型与性能预算

| 机型 | 三角形 | 游戏座位数 | 起落架显示 |
|---|---:|---:|---|
| 教练机 | 程序生成 | 3 | 简化模型显隐 |
| 支线客机 | 程序生成 | 70 | 简化模型显隐 |
| A330-300 | 10,500 | 300 | 添加简化起落架，G键显隐 |
| A350-900 | 20,547 | 330 | 原LandingGear节点，G键显隐 |

单张2048×2048 RGBA图集约16MiB，合并卫星与飞机纹理；使用模型法线及简化高光；未使用法线贴图或原GLB高光扩展。地面投影为简化近似。
地面9.6公里方形网格约1.4万顶点，异步生成并缓存；原GLB不在运行时重复解析。
飞机目前每帧在CPU变换并上传，没有GPU实例化或动画LOD。20/30帧上限是配置目标，实际帧率待测。
飞机质量、推力、座位数等均为游戏参数，没有按实机性能标定，不能作为飞行训练。
第一人称采用自建的简化三维驾驶舱；原始外部GLB不包含驾驶舱内饰。原模型没有襟翼骨骼动画，襟翼按键影响物理参数。
assets中的模型预览PNG是软件绘制的资源核对图，不是Windows游戏截图。

## 第一次起飞

1. 客机放50%襟翼：F按两次；起落架放下，发动机默认开启。
2. W约2秒到满推力，保持中心线。
3. 教练机约110、支线机约220、A330约245、A350约255公里/时开始短按↓抬头，俯仰约7–9度。
4. 等待离地并爬升到200米。载荷会影响加速和离地；不要持续拉杆或在低速大幅滚转。
5. 返场对准X=0、Z=-1800～1800的3600米跑道，G放起落架、F逐步放襟翼、S减推力。
6. 控制下降率低于5米/秒、接地坡度低于约17度；接地后空格刹停。

本地Z方向沿近似034度跑道方向；卫星图坐标按此旋转，图像北向正确。
这些速度是本原型的操纵提示，不是实机操作资料。

## 菜单与按键

菜单打开时暂停飞行动力学、任务计时和昼夜；点击“开始 / 继续飞行”解除暂停。
换机、登机、切换地形需要在跑道停稳。换机重置本次任务，保留积分和执照。
重新出发保留机型、乘客和燃油；事故恢复最多扣500积分并降低维护状态。

| 按键 | 功能 |
|---|---|
| W/S | 增减推力；步行前后移动 |
| ↓/↑、←/→ | 俯仰、滚转 |
| A/D、空格 | 方向舵、地面刹车 |
| F/G/I | 襟翼、起落架、发动机 |
| L/C | 辅助回正、视角切换 |
| V | 停留刹车开关 |
| E | 停稳后步行；距飞机10米内返回 |
| 1–5 | 执照、运输、旅客、计时、摄影任务 |
| K | 摄影航点打卡并保存BMP |
| B/H | 购买出租飞机、加油维修 |
| T/N | 季节切换、时间前进3小时 |
| P/R | 暂停、重新出发 |
| Tab/Esc | 打开或关闭菜单 |
| F1/F5 | 中文帮助、保存 |

客机襟翼循环0→25→50→100→0%，教练机为收/放两档。
季节配色用于虚构地形；卫星影像不会变成实时四季图。
中文HUD采用Windows Microsoft YaHei字形缓存；若系统缺少中文字体，需安装Windows中文字体组件。

## 生涯和保存

先完成执照任务：起飞、爬升至200米、返场停稳。高级任务仍是四航点返场流程。
执照/运输/旅客/计时/摄影基础奖励为1500/2400/1800/2600/2000；客机旅客任务再加乘客人数×30。
乘客每人按85kg计入载荷。出租飞机6000积分、最多6架，每完成任务额外出租机各收入120；维修加油300。
摄影在距离航点350米内、高度80–650米时按K，截图成功写入后才确认航点。

存档、照片和日志在%LOCALAPPDATA%\FlightCareerAir：

v0.37诊断例外：--benchmark和--smoke-test输出分别在diagnostics\benchmark、diagnostics\smoke，不保存生涯/痕迹，也不读取正常游戏的存档或自定义机模。普通游戏位置及保存方式不变。见DIAGNOSTIC_STORAGE.md。

- state.txt / state.bak：完整飞行状态及上次有效备份。
- career.txt：旧生涯迁移来源。
- tracks.txt：最多400段地面痕迹；切换地形清空当前痕迹。
- photo_N.bmp：摄影打卡；startup.log：启动和图形诊断。

v7写入机型、乘客、地形、光影与停留刹车，读取v3–v6；旧版本不能读取v7。
每30秒、F5、任务完成、换机、乘客调整、维修和退出保存。读取失败不替换当前状态。

## 验证与图形检查

Linux g++ C++17 / -Wall -Wextra -Werror -pedantic数值检查通过；地址与未定义行为检查通过（关闭泄漏扫描）。
新增太阳向量、曝光边界、光影设置存档与v5迁移、模型法线有效性检查。覆盖教练机/支线机起飞和进近刹停、A330/A350满载起飞、乘客载荷、五种任务、经营、存档迁移、地形差异、卫星投影、模型尺度/朝向、图集读取与损坏资源拒绝。

check_graphics.bat会在你的Windows上分别用DX11和DX12展示A330/A350，分别渲染三帧并保存截图，追加傍晚检查，不推进生涯。
截图名为smoke_DX11_2_noon.bmp、smoke_DX11_3_noon.bmp等，另有A350的_sunset.bmp傍晚检查图。
成功退出还需要你查看BMP确认中文、卫星图和飞机外形正确。

--dx11强制兼容；--dx12禁止回退；--low低分辨率及20帧上限；--warp仅软件诊断。
--a330、--a350、--airliner仅配合--smoke-test选择检查机型，正常换机用中文菜单。
需要Windows的DX12运行时，DX11回退不代表兼容Windows 7。

未验证Windows构建、DX11/DX12运行、菜单点击、GPU截图、字体显示或目标硬件帧率。本包没有编译好的EXE。
全CFD、完整软体结构、真实日食、完整航电、联赛和云串流尚未实现；路线见阶段任务清单.md。
