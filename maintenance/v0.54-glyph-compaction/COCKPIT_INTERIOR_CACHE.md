# v0.94 座舱固定内饰缓存

本地座舱绘制的座椅、窗框、固定仪表边框、开关外壳和装饰件在首次使用时建立缓存。普通风挡和 777 风挡分别按需建立。每帧将缓存复制到已有座舱缓冲区，再生成当前仪表、文字、按钮状态和油门杆。缓存保存原始顶点，最终舱内材质标记仍写在每帧的副本上。

缓存命中用于单位矩阵的本地座舱绘制。传入其他变换矩阵时沿用原始生成函数，保留变换与浮点计算顺序。

CPU 检查中普通内饰为 9,576 个顶点，777 为 9,684 个顶点。当前容器容量各占 786,432 字节，两者均建立时约 1.5 MiB。检查逐字节比较原始构建与缓存输出、重复帧及追加前缀。Windows 检查还使用实际 DirectXMath 比较单位矩阵、平移、旋转和缩放的输出。

本轮减少固定几何的重复生成，没有测得目标机 FPS 提升。Boot Camp 上以相同 DX11、FXAA 和分辨率对比 v0.93/v0.94 的 777 座舱基准，保留两版截图、P95 帧间隔和峰值工作集。普通模式再点检油门、起落架、襟翼、仪表断电及亮度，确认动态状态仍正确更新。
