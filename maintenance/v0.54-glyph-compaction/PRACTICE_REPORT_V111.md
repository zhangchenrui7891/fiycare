## v0.111 · 2026-11-25 · A330 进近练习接地复盘工具

v0.110 把 AGL 加入进近练习的大字仪表，并用 Windows 软件渲染截图确认没有盖住黄色引导。本版解决实机试飞后的复盘问题。双击 report_a330_final.bat，将使用 Windows 自带的 PowerShell 读取最近创建且有启动日志的练习目录。也可以将某次 sessions 子目录拖到该批处理图标上，查看指定练习。完整包沿用 v0.110 的模拟器 EXE 和正式资源，游戏窗口仍显示 v0.110。工具离线读取已有日志，只在复盘时运行。

每次接地各列一组数据，包含练习序号、垂直速度、成绩、距中心线距离（有效评分时）和进程工作集。接地前后各取六秒内最近的一行有效前台 A330 驾驶舱记录，显示采样时间、FPS、P95 帧时间、样本数、后端、渲染分辨率、FXAA 和限帧设置。等于接地时间的行归在“前”，选择记录时排除其他练习次序。P95 对应截至该行时刻的滚动样本，记录间隔约五秒。缺少接地、时间窗口、内存或 CSV 时给出相应提示。

已知差距：三维交互座舱、11 种机型配置、FXAA、浦东本地影像、生涯和简化进近均有工程实现。机型专用航电、天气和机场运行细节仍待完善。现有数值测试覆盖进近到接地、滑跑，尚缺从冷舱到关车的人工航班验收。本轮没有目标 MacBook Air 的新日志；下一步在 Windows 10 Boot Camp 用正式资源飞一遍相同进近，将 P95 与相应的分辨率、限帧、工作集和驾驶舱截图一起检查。

验证：Linux Release 49/49 项 CTest 通过。Windows Server 2022 的 Windows PowerShell 5.1 运行了两次接地的构造日志，验证接地前后不会选中跨次序的行，以及外视角筛除、未评分、内存未知、缺 CSV 和无接地。还在临时用户目录通过 cmd.exe 执行实际批处理入口，自动定位含空格路径的练习目录。Windows 同一工作流通过兼容版构建、MSVC 进近与滑跑检查、简化资源的 DX11 WARP 截图和两次启动独立建档。构造日志内的 FPS、P95 和内存均为输入样例。本轮没有测量 HD 6000 游戏性能。
