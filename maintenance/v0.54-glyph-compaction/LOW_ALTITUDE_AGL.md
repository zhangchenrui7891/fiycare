# v0.98 PFD 低空 AGL

在 PFD 姿态区下方加入 `AGL n m`。值为 Flight::y 减去当前地形高度，使用飞机坐标参考点；QNH 仅影响原有 ALT，不影响 AGL。地形模式切换后即时使用对应地形。机体参考点在地面上方，所以停机时读数通常为机型 gearHeight 的四舍五入值，并非零。此处没有模拟雷达高度计天线、波束、姿态遮蔽或传感器误差，不能视为完整无线电高度系统。

原始高度在 0 至 750 m（含边界）显示，超过 750 m 隐藏；750 m 是游戏显示规则。非有限输入、减法溢出或参考点低于地形时显示 `AGL --- m`。数字四舍五入到整米，显示/隐藏先按未舍入高度判断。航电断电后随三块屏幕熄灭。使用独立黑底区域（PFD 102,114 至 198,132），与 134 行开始的 STALL 提示保留间隙，不改变控制热点、存档或飞行动力学。

检查：纯格式测试覆盖参考点、舍入、750 m 边界、负高度、无效输入与溢出；真实 glass::draw 的 CPU 适配器覆盖 11 机型、两种地形、三档 QNH、八种高度，共 528 组绑定及失速/断电；Windows 实际 GDI 字体检查验证新标签在预留区域内。将实际输入改为气压高度的对照变体须失败。生成布局图是生产几何加替代字体的正投影预览，不是模拟器截图。

尚待 Boot Camp DX11 检查：训练机、A350 与 777 停机、起飞、低空、越过 750 m、山地与浦东地形、QNH 调节、失速与断电时的可读性及遮挡；记录相同场景 P95 和峰值工作集。未进行 Windows 模拟器/GPU/HD6000 实机验收，不以 CPU 数值检查证明真实仪表或性能。本版仍为共用训练座舱，与机型专用航电/FMS 有明显差距。
