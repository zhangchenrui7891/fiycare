# v0.80 游戏内菜单完整点击判定

旧菜单只在 WM_LBUTTONUP 检测当前位置，因此没有对应按下的松开、从空白处拖入、从另一个按钮拖入，都可能执行读取、重开、退出等命令。

本版记录按下的按钮命令并捕获鼠标，松开时先消费按下记录、释放本窗口捕获，再要求仍处于同一按钮范围才能入队。重复松开不能重复执行。失焦、原生菜单、移动/缩放、捕获丢失或主循环处理其他菜单命令时取消未完成点击。原生 Windows 菜单自身的 WM_COMMAND 行为不变。驾驶舱油门与环视继续优先使用已有事件路径。

检查工具 tools/check_pointer_integration.py 提取实际 main.cpp 鼠标与取消消息处理语句，以 CPU Win32 替身编译运行。覆盖无按下松开、从空白拖入、跨按钮、拖出后再次松开、捕获丢失、缩放、失焦、原生菜单、正常点击一次及重复松开；保留油门/环视互斥、两种释放顺序、缩放坐标与新按下恢复。旧 main.cpp 可以编译但在无对应按下的松开断言失败。严格便携和 ASan/UBSan 记录见 validation_v080。

目标机验收（未执行）：带资源 Windows 构建打开主菜单，以读取/重开按钮为例做以上各类点击，确认只有同一按钮的完整点击执行。检查按住按钮切出窗口、改变大小、切换菜单后松开不触发；正常菜单操作、油门拖动和环视仍有效。再完成 Boot Camp 启动、固定场景帧时/RAM 与完整航班记录。

这是简化游戏界面的交互修复，无贴图/画质或存档格式变更，也没有真实 Windows 消息投递、鼠标、GPU、HD6000 性能或画面验收。v0.80 是连续工程版本，不表示已达到成品。
