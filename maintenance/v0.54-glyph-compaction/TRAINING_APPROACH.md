# v0.34 入口基准的训练进近

仅用于本游戏的理想几何提示，不是实际机场ILS、航图程序或自动着陆。它不会操纵飞机，也不会改变原有航向/高度/航点保持。

## 入口、距离与符号

| 训练跑道 | 正向入口（+Z入场） | 反向入口（-Z入场） |
|---|---|---|
| 浦东训练跑道 | X=0，Z=-1800 | X=0，Z=1800 |
| 东海训练机场 | X=3500，Z=1800 | X=3500，Z=3200 |

坐标是本游戏局部世界，不是经纬度；正/反不是实际跑道号或真/磁北航向。旧版使用跑道中心距离，现改用相应入口前的沿轴距离。HUD明确标为“入口”，三维座舱显示正/反。

- LOC正值：飞机位于入场方向右侧，需要向左回中；负值相反。+Z入场时世界+X是右侧，-Z入场时世界-X才是右侧。
- GS正值：飞机高于训练路径；负值：低于路径。它是米制几何偏差，不是真实无线电点偏差。
- 理想目标高度 = gearHeight + 15.24m + tan(3°) × 入口距离。15.24m是游戏选择的50ft轮子入口净空，不是实际天线TCH，也不按真实机型天线位置校准。
- 入口外1000m时，目标轮子高度为约67.648m；入口处为15.24m。Flight.y还需加对应机型gearHeight。

## 显示条件与目的地

| 情况 | 提示 |
|---|---|
| 旅客航班mission=2且stage=1 | 仅计算既定arrivalRunway，不因附近机场而改选 |
| 其他训练 | 最近的合格入口；候选重叠区可能切换，没有目标锁定/迟滞 |
| 跑道入口前0—12000m、侧偏≤2500m、几何高度0—1500m | 还须满足入场方向条件 |
| 机头与跑道入场轴夹角≤60° | 游戏显示窗口，不是ILS服务区 |
| 水平地速>5m/s | v0.89 起，地面航迹与入场轴的夹角也须≤60° |
| 航电断电、地面、事故、非法目的索引或无效数值 | 隐藏，不悄悄改选别的目的地 |
| 已越过入口 | 隐藏；不提供拉平、接地或滑跑控制 |

地形/障碍物、无线电频率/信号、真实机场标高/天线、最低标准/决断高度、进离场/复飞和自动着陆均未实现。两个方向是两条独立理想训练路径，不是现实ILS背航道。游戏的其他通用调试遥测不在此次断电隐藏范围内。

## 代码与可重复检查

- src/approach.h：Flight纯几何查询及Snapshot目的地/供电/地面上下文包装；固定四个候选，不修改状态或存档格式。
- src/main.cpp、src/cockpit.h：共同调用Snapshot包装；显示训练类型和方向。HUD距离改为入口距离。
- approach_tests.cpp：v0.33公式摘录复现、264组机型/机场/方向/距离样本、12001个一米路径连续性样本、目的地/供电/地面/边界及v16恢复，并覆盖横切、侧风和进入角度范围后的重新显示。
- tools/check_approach_integration.py：编译实际HUD语句并检查输出；check_cockpit_geometry.py执行实际座舱函数、捕获送入字体的字符串。
- 日志与边界：validation_v034/VALIDATION.json。Linux CPU通过不等于Windows/MSVC、字体、屏幕布局、真实消息或GPU验收。

## Windows验收（尚未执行）

先在新目录运行build_vs.bat。停稳检查无进近提示，再建立临时测试飞行；以下需要实际飞行到对应入场一侧，或者在测试副本中用调试器定位。没有新增传送菜单或自动进近功能。

1. 两机场各从+Z和-Z方向进场，确认“训练进近”名称、正/反以及目的机场正确。旅客航班经过较近的出发机场时，不应被它替换目的提示。
2. 正向飞机位于中线世界+X侧，应为LOC右/正；反向同一世界+X侧，应为LOC左/负。回中为0，高于/低于理想路径分别显示GS高/低。
3. 对照上表入口，距离接近0时不应仍显示700m或1800m；越过入口应隐藏。入口前1000m的目标轮子高度约67.648m，仅核对游戏公式，不是现实飞行高度建议。
4. 背离、横切或明显超出游戏包线时不显示；暂停时仅保持当前有效场景，不代表自动驾驶已捕获。
5. Q/M/Y切断实际供电后提示隐藏；恢复电源并保持有效进近场景后出现。先验证电池/发电机真实状态，不能只看开关名称。
6. 切换内外视角确认HUD/座舱目的地和方向一致；拍摄文字布局，检查长机场名称是否截断、遮挡。CPU字体替身没有检查这些。
7. 按KEYBOARD_EVENTS.md与KEYBOARD_RECOVERY.md回归按键；记录同场景60秒性能。不得用几何采样点数代替HD6000帧率。

尚无Windows实机证据、EXE或新的游戏截图。请勿将此训练几何用于真实飞行导航。
