# v0.82 777 外模索引绘制

v0.81 已在 CPU 端缓存 777 外模的唯一顶点。v0.82 把变换后的唯一顶点留在原场景顶点缓冲区中，再用独立的 32 位索引缓冲绘制。DX11 使用 DrawIndexed，DX12 使用 DrawIndexedInstanced。场景在外模前后的三角形按原顺序提交，保留起落架显隐、贴图、法线和三角形绕序。普通机模继续使用其原有绘制路径。DX12 继续沿用每帧完成后的既有 GPU fence 等待。

| 777 外模状态 | 三角形数 | v0.81 上传字节 | v0.82 上传字节 | 减少 |
| --- | ---: | ---: | ---: | ---: |
| 放轮 | 30,516 | 4,394,304 | 1,491,648 | 66.1% |
| 收轮 | 20,916 | 3,011,904 | 1,376,448 | 54.3% |

数据按实测几何计数与顶点和索引大小计算，仅统计外模的逻辑上传量。收轮时仍变换全部 23,447 个唯一顶点。指标不包含索引缓冲容量余量、图形驱动拷贝、额外绘制调用或 GPU 顶点缓存命中率。当前代码没有测得实际帧率收益。

在 Boot Camp 上用相同的 DX11、分辨率、FXAA、地点、机位和帧率限制启动 v0.81 / v0.82。选择 777 并使用追尾视角，分别在放轮和收轮场景比较截图、P50 / P95 帧时间、进程内存和 GPU 占用。确认机身涂装、起落架和 HUD，切回驾驶舱再切到空客，检查无残留外模。驱动能启动 DX12 时重复验证。然后执行一次带资源启动后的滑行、起飞、进近、着陆到任务结算。当前无目标机实测结果。
