# v0.85 · 777-300ER 前风挡原型

777 专用窗框包括向后倾斜的风挡上沿、左右立柱、窗台和略偏机长右侧的挡柱。几何沿用现有机长眼点和舱内材质，与现有机载交互共用坐标。两块风挡开口透出原有地景。该原型的尺寸为程序化设定，未用真机图纸校准。驾驶舱仪表和机载系统继续使用当前共用实现。

新旧窗框都提交 252 个顶点（84 个三角形），没有增加贴图、分配或绘制批次。几何检查覆盖水平正前方及两侧开口、右侧挡柱可见性、三块显示器中心和三种油门位置下的 27 个控制体中心。测试仅执行 CPU 几何与射线相交。

## Boot Camp 对照

在 v0.84 和 v0.85 使用相同的 DX11、FXAA 设置执行同一 777 驾驶舱预设。保留两版各自的 `benchmark_final.bmp`、`performance_summary.txt` 和 `startup.log`，比较跑道在正前方的可见性、挡柱位置、各仪表是否清晰，以及有效报告中的 P95 帧间隔。另从普通飞行进入 777，左右环视并依次操作油门、襟翼、起落架和航电，检查实体遮挡与点击结果。Windows CI 可检查源码编译，以上验收依赖目标机。
