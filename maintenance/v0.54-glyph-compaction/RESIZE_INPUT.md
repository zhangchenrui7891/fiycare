# v0.74 窗口移动/缩放输入恢复

进入Windows交互式窗口移动/缩放时，暂停键盘并取消驾驶舱鼠标输入、清空尚未应用的命令、清除左键标记；仅在本窗口持有鼠标捕获时释放捕获。已经应用到飞行状态的油门保持不变。恢复后需要重新按下鼠标按钮，不延续旧坐标下的拖动。

测试抽取main.cpp中的实际WM_ENTERSIZEMOVE和鼠标消息语句，以CPU函数代替Win32 API。覆盖油门/环视×本窗口/其他窗口捕获四种组合，960×540变为1920×1080后移动不产生旧动作，重新按下后可继续拖动。相同测试对v0.73代码在取消状态断言处失败；本版通过。这里只证明模拟消息下的逻辑，不代表实际Windows投递和窗口管理行为。

人工待验收：在Boot Camp窗口模式下分别开始油门拖动、环视，再进入系统移动/缩放（包括系统菜单路径），变更窗口尺寸后松键、移动鼠标，检查没有油门跳变/视角漂移；重新按下后能正常操作。重复检查Alt-Tab、菜单、全屏切换。记录实际输入设备、窗口尺寸、渲染后端与画面。当前没有目标机连接，以上未执行。
