# v0.48 · Assimp 开启的 Windows 构建与导入检查

日期：2026-11-01。基线：v0.47文件版本28，ZIP CRC与2023项SHA256核对通过。

## 本轮实际改动

此前Windows只编译Assimp关闭的程序。本轮新增tools/check_windows_importer.ps1与Windows CI：开启FCAIR_WITH_ASSIMP，编译主程序、asset_import命令行工具和自包含导入测试；资源复制仍关闭。正常build_vs.bat默认配置保留。

新增asset_fixture_tests.cpp，用临时生成的ASCII及中文目录/模型/MTL/外部PPM贴图运行真正的Assimp导入，核对1个三角形、贴图解码、RGB顶点烘焙、中文路径原生fcmesh读回、不烘焙选项与无效缩放拒绝。样例使用非退化UV，不代替真实复杂GLB/FBX机模验收。

完整读取后确认既有asset_import.cpp已使用u8path，未修改导入实现。本轮不把已有UTF-8处理重新算作修复。实际产品改动是CMake的新检查目标、版本文字与构建/依赖恢复工具，没有新增玩法、画质或帧率优化。
